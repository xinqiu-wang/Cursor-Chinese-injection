Cursor 中文注入工具 · Windows 便携版

使用方法
1. 把整个压缩包复制到目标电脑，先解压。
2. 双击 CursorZhCNTool.exe（窗口入口），或运行“启动工具.vbs / 启动工具.cmd”。
3. 工具会自动查找已安装的 Cursor；未找到时点击“选择程序”，选中 Cursor.exe。
4. 点击“一键注入中文”，查看阶段进度和日志。
5. 显示成功后，完全退出并重新打开 Cursor。

还原：点击“还原原版”。仅使用当前电脑、当前安装和当前版本验证过的备份。
备份：点击“查看备份”。数据保存在本机 %LOCALAPPDATA%\CursorZhCNPortable 中，
      不会混入另一台电脑的备份。脚本包可放在任意目录或 U 盘上。

运行要求
- Windows 10/11，已安装兼容的官方 Cursor。
- 不需要另外安装 Node、Python，不需要联网下载运行环境。
- 使用 Windows 自带 PowerShell、WinForms 和 Cursor 自带运行环境。
- 主要脚本为 CursorZhCN.ps1，窗口入口仅调用该脚本，不会弹出命令行窗口。
- 若程序安装在受保护的目录并提示拒绝访问，关闭工具，右键“启动工具.cmd”以管理员身份运行。
- 不会强制结束 Cursor，也不会修改你的聊天输入、代码、账户或网络配置。

版本与边界
已在 Cursor 3.27.14 上验证。新版本会检查入口结构、原文件校验值和完整 JavaScript 语法。
兼容时可重新注入现有翻译；结构变化或发现未知修改时会停止，不会把旧版备份覆盖到新版。
新增文案、第三方扩展或外部网页仍可能有未翻译内容。

如果该电脑之前已安装本系列维护程序，工具可接管同一安装中可验证的原始备份。
若只有旧补丁、没有可验证备份，请先修复或重装官方 Cursor，再注入。
